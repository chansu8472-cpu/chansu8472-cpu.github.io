글 관리

GitHub 계정을 확인한 뒤 글을 작성하거나 삭제할 수 있습니다.

작성자 확인

처음 한 번만 준비해 주세요
  1. GitHub에서 Fine-grained token 만들기
  2. Resource owner를 chansu8472-cpu, Repository access를 이 블로그 저장소 하나로 선택합니다.
  3. Repository permissions에서 Contents: Read and write를 선택하고 토큰을 만듭니다.
  4. 만든 토큰을 아래 칸에 붙여 넣고 계정을 확인합니다.

토큰은 GitHub 계정 확인과 이 저장소의 글 처리에만 사용됩니다. 페이지에 저장하거나 다른 서비스로 보내지 않으며, 로그아웃하거나 페이지를 닫으면 메모리에서 사라집니다. 토큰을 다른 사람과 공유하지 마세요.

새 글 작성

글자를 선택한 뒤 도구를 누르면 선택한 부분에 서식이 적용됩니다. 미리보기에서 게시될 모양을 확인할 수 있어요.

등록된 글

글은 GitHub 저장소의 _posts에 저장됩니다. 사이트 반영까지 잠시 걸릴 수 있습니다.
